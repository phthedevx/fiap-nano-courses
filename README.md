## 📂 Estrutura do Repositório

Cada pasta de curso segue este padrão:
- `/notes`: Resumos dos módulos e conceitos teóricos.
- `/exercises`: Mini laboratórios e desafios propostos.
- `/projects`: Projetos práticos autorais baseados no aprendizado.

## 🚀 Como acompanhar

Para rodar os códigos de Java ou visualizar os diagramas:
1. Clone o repositório: `git clone https://github.com/phthedevx/fiap-nano-courses.git`
2. Navegue até a pasta do curso desejado.
3. As anotações estão em formato **Markdown**, prontas para leitura no VS Code ou GitHub.
